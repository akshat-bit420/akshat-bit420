## 📂 Projects

### 🤖 [AI Agent](https://github.com/akshat-bit420/ai-agent)

An AI assistant built with the OpenAI SDK that can list, read, write, and execute files within a sandboxed working directory. It uses a feedback loop to diagnose errors and attempt fixes across multiple steps.

**Focus:** Tool calling, agent loops, file operations, and controlled execution.

### 📖 [Folio — Offline PDF Reader](https://github.com/akshat-bit420/Folio)

A desktop-first, browser-based PDF reader designed around a calm, Kindle-inspired reading experience. Built with React, TypeScript, and PDF.js, with local storage for reading progress, bookmarks, highlights, and notes.

No accounts, no cloud dependency — just your PDFs and your reading progress.

**Focus:** Frontend architecture, browser storage, PDF rendering, and understanding how components and modules connect in a real application.

### 📊 [Viz-Flow — Sorting Visualizer](https://github.com/akshat-bit420/viz-flow)

A sorting visualizer that animates Bubble Sort, Insertion Sort, Merge Sort, and Quick Sort, with live comparison and swap counters.

**Focus:** DSA, algorithm visualization, and making abstract algorithm behavior easier to understand.

### 🐚 Custom Shell — Work in Progress

Building a Unix-like shell through CodeCrafters to understand what happens behind a terminal command. Working through command parsing, quoting, built-ins, and input/output redirection.

**Focus:** Processes, system calls, parsing, file descriptors, and operating-system fundamentals.
